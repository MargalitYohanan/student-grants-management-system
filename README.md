Student Grants Management System



A full-stack web application for managing student grant applications.



Summary



The system allows students to register, log in, submit grant applications, track their application status, and resubmit applications when needed.



Administrators can view all submitted applications, review application details, and update their status to Approved or Rejected. New applications are initially set to Pending.



Technologies



Client side: Angular, TypeScript, HTML, CSS.



Server side: Node.js, Express, JavaScript, REST API.



Database: MongoDB with Mongoose.



Authentication: JWT and bcrypt.



Running the Project

Server

cd server

npm install

npm start

Client

cd client/my-project

npm install

ng serve



The client application runs at http://localhost:4200/.
